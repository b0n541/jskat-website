For developers

Build your own Skat AI

JSkat includes several computer players and makes it possible to add your own. This guide shows you how to build the project, find the relevant code, and connect a new player to the game.

Set up the project

Build JSkat and find your way around

You need Git and at least JDK 21. The Gradle wrapper is included in the repository, so you do not need to install Gradle separately. A Java IDE is useful, but the first build only needs a terminal.

01

Fork and clone the repository

Fork JSkat on GitHub and clone your fork. You can then prepare and publish changes in your own repository.

git clone https://github.com/YOUR-NAME/jskat.git cd jskat
02

Build the project

The full build checks the project. The second command creates an executable JAR file.

./gradlew clean build ./gradlew fatjar
03

See where the code lives

Game logic and AI components live in jskat-base. The JavaFX interface lives in jskat-gui, while app contains the application entry point and packaging.

04

Start with an existing player

The smallest complete example is AIPlayerRND in the org.jskat.ai.rnd package. Copy its structure into your own package, such as org.jskat.ai.myplayer, and keep your class derived from AbstractAIPlayer. The base class provides shared game state and identifies the implementation as an AI player. Your class also needs a public no-argument constructor because JSkat creates ordinary AI players through reflection.

05

Implement and register the new AI player

JSkat asks the AI for decisions at several points during a game. The inherited knowledge value gives you access to information such as the player’s cards, seat, previous bids, current trick, declarer, and game contract.

  1. Prepare the lifecycle Use prepareForNewGame() to reset your own state before each game. startGame() is called once the declarer and game contract are known.
  2. Define the bidding strategy bidMore(int nextBidValue) returns the next bid or 0 to pass. holdBid(int currBidValue) decides whether to hold another player’s bid.
  3. Handle the Skat and game announcement pickUpSkat() decides whether to pick up the Skat. getCardsToDiscard() must then return exactly two cards. announceGame() returns the chosen GameContract.
  4. Play a legal card Start with getPlayableCards(knowledge.getTrickCards()). Choose only from the returned list so following suit and the other game rules remain enforced.
  5. Add special cases and cleanup Implement playGrandHand(), callContra(), and callRe(). Use finalizeGame() to update statistics or perform a learning step after the game.

The core of a legal card choice can look like this:

public final class MyAIPlayer extends AbstractAIPlayer { public MyAIPlayer() { // Called reflectively by JSkat. } @Override public Card playCard() { CardList playable = getPlayableCards(knowledge.getTrickCards()); return chooseCard(playable); } // Implement the remaining abstract decisions // following AIPlayerRND as a reference. }
Make the new AI visible in the start dialog

Add its fully qualified class name to JSkatPlayerResolver.getAllAIPlayerImplementations(). Then add a readable label to SkatSeriesStartDialog.PlayerTypeCell. Add the corresponding text key to jskat_strings_en.properties and jskat_strings_de.properties.

Put tests in the matching package below jskat-base/src/test/java/org/jskat/ai. Start with small, deterministic bidding or card-selection cases and run them with ./gradlew :jskat-base:test.

06

Submit your contribution

Create your feature branch from develop. Open a pull request back to develop and describe the idea and behavior behind your change.

Other ways to contribute

You can start with something smaller

A reproducible bug report, another test case, clearer documentation, or an interface improvement all help. The open issues show what people are currently working on and where help is needed.

Looking for something to work on?

Ask a question or pick an issue that matches your interests.
