A project with a long history

Free Skat, made in the open

Jan Schäfer started JSkat because he wanted a free computer game that supported both the official Skat rules and the variations people play around the pub table. Players and developers have helped the project grow ever since.

The code is on GitHub under the Apache License 2.0. Take a look, build your own computer player, or send us a change you would like to see in the next release.
