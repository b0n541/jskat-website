Open since the first deal

A game built to be shared

Jan Schäfer started JSkat to create a free computer Skat game for official rules and the variations people enjoy around the pub table. Contributors have kept that idea moving forward ever since.

The code is available under the Apache License 2.0, so you can study it, adapt it, and help make the project better for the next player.
