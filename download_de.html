Für Mitwirkende

Die Entwicklungsversion bauen

Klonen Sie das öffentliche Repository, um die aktuelle Entwicklung zu verfolgen, den Code zu erkunden oder einen Beitrag vorzubereiten. Der Gradle Wrapper ist bereits enthalten.

git clone https://github.com/b0n541/jskat.git cd jskat ./gradlew clean fatjar
  • Voraussetzung zum Bauen Nutzen Sie mindestens JDK 25 und prüfen Sie die README-Datei im Repository auf aktuelle Angaben.
  • Entwicklungsablauf Erstellen Sie Ihren Feature-Branch von develop und richten Sie Pull Requests wieder dorthin.
  • Lizenz Der Quellcode steht unter der Apache License 2.0.
