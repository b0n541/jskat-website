Für Mitwirkende

JSkat aus dem Quellcode bauen

Klone das Repository, wenn du den neuesten Code ausprobieren oder einen Beitrag vorbereiten möchtest. Der Gradle Wrapper ist enthalten, du musst Gradle also nicht separat installieren.

git clone https://github.com/b0n541/jskat.git cd jskat ./gradlew clean fatjar
  • Java Nutze mindestens JDK 25 und prüfe die README-Datei im Repository auf aktuelle Angaben.
  • Branches Erstelle deinen Feature-Branch von develop und richte Pull Requests wieder dorthin.
  • Lizenz Der Quellcode steht unter der Apache License 2.0.
