For contributors

Build the development version

Clone the public repository to follow current development, explore the code, or prepare a contribution. The project includes its Gradle wrapper, so no separate Gradle installation is needed.

git clone https://github.com/b0n541/jskat.git cd jskat ./gradlew clean fatjar
  • Build requirement Use at least JDK 21 when building from source and check the repository README for current details.
  • Development workflow Create your feature branch from develop and open pull requests back to it.
  • License The source code is available under the Apache License 2.0.
