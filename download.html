For contributors

Build JSkat from source

Clone the repository if you want to try the latest code or prepare a contribution. The Gradle wrapper is included, so you don't need to install Gradle separately.

git clone https://github.com/b0n541/jskat.git cd jskat ./gradlew clean fatjar
  • Java Use at least JDK 21 when building from source and check the repository README for current details.
  • Branches Create your feature branch from develop and open pull requests back to it.
  • License The source code is available under the Apache License 2.0.
